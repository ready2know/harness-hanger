# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give constructive feedback, and keep discussion about
the work. Harassment and personal attacks are not tolerated in any project space: issues, pull
requests, discussions, or any other channel.
